# Amythest 1.7.0

Messages becomes a full terminal client: an irssi-style chat view with every
conversation one keystroke away, search that jumps straight to a message, Slack
threads, and files and pictures in both directions. Work gains milestones, so a
stretch of work such as a production deploy can be marked and later collected,
and messages can be put on a project's wall. This release also adds shared
canvases, the workspace dashboard, and task evidence reviews. Each platform
archive includes `amythest`, `amy`, and `amythest-collector`.

## Messages

- `amy messages chat` is an irssi-style client: numbered windows, an activity
  bar, and one input line for text or `/commands`. Set `"view": "chat"` under
  `client` in `messages.json` to open it from plain `amy messages` (and so the
  Herdr App's Cmd+Shift+M); `amy messages focus` keeps the queue view.
- Window 1 lists what is waiting on you beside the selected conversation's recent
  messages. Ctrl+F lists every chat by service (channels, groups, people, Slack
  threads under their channel); Enter opens one in its own window.
- `amy find` searches message text and senders and opens the message in
  Messages; the gateway keeps a full-text index and hands jumps to the open view.
- Reply to a specific message by its short tag (`/reply`), and reply in or open
  Slack threads (`/thread`, or `t` and `>` in the queue view).
- Files arrive with their messages from Signal, Telegram, iMessage (HEIC photos
  become JPEG) and Slack, and pictures draw inline as the wall draws them.
  Send files with `/attach`, by pasting or dropping a path, or with Ctrl+V for
  the clipboard's picture; Slack takes one file per message.
- Slack: list every channel and DM you are in (`amy-agent-messages channels`),
  import DMs as well as channels, and import on a schedule
  (`scripts/install-agent-sync.sh`). Imported Slack files never enter the
  model's context.
- iMessage can run in the background under launchd from a small signed app that
  holds its macOS permissions (`scripts/install-imessage-service.sh`). Its text
  is now decoded from Messages directly; `scripts/repair-imessage-text.py`
  fixes messages imported with a stray leading character.
- Queued replies report when they are sent, handed over or fail. `/grant` lets
  agents use one conversation for a while; `/revoke` ends it.
- The queue and conversation pages read through indexes, so large inboxes stay
  quick, and long conversations load a page at a time.

## Milestones and the wall

- `amy milestone start NAME` marks a stretch of work on the workspace's project
  and `amy milestone end` closes it. `amy milestone collect NAME` gathers its
  window for review or analysis: overlapping sessions and runs, artifacts and
  agent notes created in it, and messages put on the project's wall during it
  (`-json`, `-o FILE`). The wall's header shows open milestones.
- Put a message on the workspace's wall with `w` in the queue view or `/tag` in
  the chat client. It appears among the wall's items (with a messages filter);
  Enter opens it in Messages.
- Wall commit diffs open in local Vim, and the workspace wall is navigable and
  includes its canvases.

## Canvases, dashboard and tasks

- Shared canvases for drawing with agents, drawn natively in a Herdr pane,
  linked from notes and cards as live drawings, and copyable as PNG.
- A workspace dashboard and Herdr quick-add shortcuts; `scripts/setup-mac.sh`
  sets up a Mac in one step.
- Task evidence reviews, message links from notes and tasks, and read-only
  agent sources; completed task reviews stay navigable.

## Upgrade and install

Back up the vault, the data directory and the messaging gateway's state before
upgrading. Work schema 2 upgrades to schema 3 for milestones; rolling back across
it also requires the corresponding `work.db` backup. On first start the messaging
gateway rewrites stored message times into a sortable form and builds its search
index, and its attachment store grows from 64 MiB to 2 GiB (sent and received).
Restore its `messages.db` backup to roll back.

```sh
tar xzf amythest-1.7.0-<os>-<arch>.tar.gz
mkdir -p ~/bin ~/.local/bin
install -m 0755 amythest amy ~/bin/
# If using the collector, install its binary and restart its sync service too.
install -m 0755 amythest-collector ~/.local/bin/
```

Restart the server after replacing its binary. Redeploy the messaging gateway
and reinstall connectors from the repository (`scripts/deploy-messages.sh`,
`scripts/install-agent-messages.sh`, `scripts/install-imessage-connector.sh`).
See [Messages](../messages-poc.md), [Slack and Outlook through Claude](../agent-messages.md),
[iMessage](../imessage.md) and [Work](../work.md).

The release includes macOS and Linux builds for AMD64 and ARM64, plus SHA-256
checksums. Archives contain only the three binaries and `BUILD_INFO.txt`; vaults,
messages, transcripts, credentials, and local configuration are not packaged.

Validation: the full Go suite, 134 web tests, connector suites for Signal,
Telegram, iMessage, Slack/Outlook and shared transport, and live checks on the
private deployment: gateway endpoints, Slack file send and import, iMessage
photo delivery and text repair, and the milestone API after the schema 3
migration.
