# Amythest 1.7.1

Milestones can now cover past work. Record a milestone with past dates, link
the messages and pull requests that belong to it, and collect it later for
review. This release also adds a one-off Slack history backfill, so older
channel messages can be imported and linked.

## Milestones

- `amy milestone start NAME -from 2026-10-01 [-to 2026-10-31]` records a
  milestone that started in the past; with `-to` it is already finished.
  `amy milestone edit NAME -from … -to … -name …` changes one, and `-to open`
  reopens it. Milestones on one project may overlap.
- `amy milestone link NAME msg:ID pr:owner/repo#N` (or a pull request URL)
  links things to a milestone whatever their time. Linking twice is harmless.
  `unlink` and `links` remove and list links.
- In Messages, `/tag [REF] [PROJECT] -milestone NAME` (chat client) and **w**
  (queue view) put a message on the wall and link it to a milestone. **w**
  shows the project's milestones, and *Wall only* is still the default.
- `amy milestone collect` counts wall messages by when they were sent, not when
  they were put on the wall, and includes everything linked. Each message and
  pull request records `via` (`window`, `linked`, or both). Linked pull requests
  show their title, state and merge time from `gh`, plus the collector's
  artifact if an agent session produced one.

## Slack backfill

- `amy-agent-messages backfill --name ACCOUNT --channel '#name' --since DATE`
  imports a channel's history back to a date, a page at a time, with thread
  replies. Messages keep their Slack timestamps, so re-running it, or
  overlapping it with `sync`, changes nothing. It needs `slack_read_channel`
  (and `slack_read_thread` for replies) in the account's `read_tools`.

## Upgrade

Back up `work.db` first. On start, the server upgrades Work schema 3 to 4,
which adds the `milestone_links` table and leaves existing data unchanged. To
roll back past it, restore that backup. The messaging gateway is unchanged.
Install the new `amy` and the agent connector (`scripts/install-agent-messages.sh`).

The release includes macOS and Linux builds for AMD64 and ARM64, plus SHA-256
checksums.

Validation: the full Go suite (including the schema 3 to 4 upgrade), the agent,
shared, iMessage, mail and Signal connector suites.
