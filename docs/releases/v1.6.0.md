# Amythest 1.6.0

Boards can now link directly to herdr workspaces. Choose a board at the top of
Kanban to see its cards, live agent tabs, dated inputs, and output in one place.
This release also adds the terminal Work wall, unified search, and the integrated
collector. Each platform archive includes `amythest`, `amy`, and
`amythest-collector`.

## Boards, workspaces, and shared inputs

- Save a board's workspace link in Board settings; the link is shared across
  browsers and preserved in the board's Markdown frontmatter.
- Switch between Board, Project, and Unassigned output. Project shows current
  agent state; herdr remains responsible for agent notifications.
- Choose the four-day window with a date selector, previous/next controls, or
  Today. Inputs, media, commits, and daily counts follow the selected local dates.
- Browse shared user messages and enlarge screenshot attachments under Inputs.
  Codex input capture is explicitly enabled per chat with
  `deploy/watch-codex.py --capture-inputs`; lifecycle-only capture remains the
  default. Assistant and tool bodies are excluded by this adapter.
- Search tabs by agent, title, tab, or machine when assigning future runs to a
  card. Results default to the board's workspace, with an All workspaces option.
- Existing favorite boards can save unrelated settings even when legacy data
  exceeds the current favorites limit.

## Terminal tools and collection

- `amy wall` shows a workspace's recent output, live-state summary, four-day
  history, image gallery, and captured commit diffs alongside ongoing work.
- `amy find` searches notes, cards, tasks, agent output, tracker tickets, and
  available herdr terminal text, with actions to open the source or matching pane.
- The integrated collector tracks terminal herdr and Herdr App sessions, stages
  immutable media, and retries delivery through its durable queue.
- Work provides private media previews, commit diffs, session project assignments,
  and grouped activity. Focus includes cross-board search and task completion.
- Search excludes archived folders by default and prioritizes exact titles.

## Upgrade and install

Back up the vault and data directory before upgrading. The data directory contains
authoritative authentication and Work databases; do not delete it to rebuild an
index. Work schema 1 upgrades to schema 2 for session project assignments. Rolling
back across that migration also requires the corresponding database backup.
The board workspace and input additions do not require a further schema migration.

```sh
tar xzf amythest-1.6.0-<os>-<arch>.tar.gz
mkdir -p ~/bin ~/.local/bin
install -m 0755 amythest amy ~/bin/
# If using the collector, install its binary and restart its sync service too.
install -m 0755 amythest-collector ~/.local/bin/
```

Restart the server after replacing its binary. See
[authentication](../authentication.md), [collector setup](../collector.md), and
[the Work module](../work-module.md) for configuration and upgrade details.

The release includes macOS and Linux builds for AMD64 and ARM64, plus SHA-256
checksums. Archives contain only the three binaries and `BUILD_INFO.txt`; vaults,
screenshots, transcripts, credentials, and local configuration are not packaged.

Validation: the full Go suite, 129 web tests, TypeScript checking, and simulated
UI checks for workspace switching, date filtering, input galleries, and scoped
assignment. Live deployment checks verify health, served assets, persisted links,
and private media retrieval. On-screen visual verification was unavailable.
